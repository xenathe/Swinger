# Swinger v0.1.0 — Initial Release

**Swinger** is a clean, customizable swing timer for WoW Forever (previously developed as XenSwing).

- Main Hand, Off Hand, and Ranged timers, independently toggled
- Custom colour, text size, bar size and spacing
- Lockable click-through bars and optional labels/countdowns
- Native Forever swing tracking, live preview, saved settings

Type `/swinger` to configure.

**Note:** Install the `Swinger` folder and remove the former `XenSwing` folder to prevent duplicated timers.
